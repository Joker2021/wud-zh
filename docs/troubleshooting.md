# 故障排查

- **版本检查 403/429**：检查 workflow token 权限和 GitHub API 限额；脚本不会用 `latest` 镜像替代 Release 版本。
- **翻译缺少 Secret**：确认仓库设置了 `YOUDAO_APP_KEY` / `YOUDAO_APP_SECRET`。缓存完整时可离线使用；有新增文案时必须有 Secret，不能跳过。
- **有道错误**：查看 Actions summary 的错误码和请求类型，不输出密钥。余额、应用服务绑定、账号频控需到有道控制台确认。
- **占位符校验失败**：失败项不会写入记忆库。检查英文上下文、术语表及翻译结果后重新运行翻译工作流；失败不会更新 `main` 或发布镜像。
- **Vue AST 解析失败**：可能上游重构了模板。停止发布；固定上游 commit，按新模板结构更新提取逻辑并补充审阅。
- **覆盖率未达 100%**：查找提取清单和 coverage 报告，补齐译文；不要降低门槛以绕过新文案。
- **容器无法启动**：先检查管理员环境变量、GHCR tag 和 `/store` 卷权限；回退到之前成功的固定版本 tag，不删除数据卷。
- **NAS 上检测不到容器**：检查 `/var/run/docker.sock` 映射和绿联 Docker socket 访问权限。该权限高，不要通过暴露 Docker TCP 端口来规避。
- **GHCR 拉取失败**：检查 package 权限、设备登录状态及镜像 tag 拼写；用已有旧版本 tag 回滚。

自动化目前未执行真实 NAS 验证。任何失败都应保留旧镜像 tag 与 `/store` 数据，再开展只读诊断。
